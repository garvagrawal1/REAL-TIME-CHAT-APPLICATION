# ChatFlow AI — Frontend Client

React.js (Vite), Tailwind CSS, Socket.io-client, React Router, Lucide Icons, and Axios client application.

## Features

- **Real-Time WebSockets**: Instant message streaming without page refreshes.
- **Multi-Tab Presence**: Tracks online/offline status seamlessly.
- **Typing Indicators**: Smooth debounced feedback for typing activity.
- **AI Suite**:
  - 🤖 **AI Assistant**: Dedicated intelligent companion panel.
  - ✨ **Room Summarizer**: Generates executive recaps from chat histories.
  - 💡 **Smart Replies**: Context-aware response pills.
  - ✨ **Improve Message**: Refines drafts for tone and grammar.
  - 🌐 **Message Translation**: Instant multilingual translation.
  - 🔍 **Semantic Search**: Natural language chat history lookup.

## Environment Variables

```env
VITE_API_URL=http://localhost:5000/api
VITE_SOCKET_URL=http://localhost:5000
```

## Running Locally

```bash
npm install
npm run dev
```
